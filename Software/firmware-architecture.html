01 System block diagram

The Xbox pad reaches the RA4M1 brain by one of three paths, never more than one at a time. A valid packet over the USB bench cable always beats the radio, and switching which path is active counts as a link loss — the turret stops and comes back disarmed.

02 Firmware flowchart

dsentry.ino is two lines: app.begin() once, then app.loop() forever. Both run in a fixed order the modules depend on — this is that order, from App.cpp.
