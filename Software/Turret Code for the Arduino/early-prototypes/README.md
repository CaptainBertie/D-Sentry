Bench sketches written before D-Sentry's state machine existed, while the hardware was still
being proven out one piece at a time: stepper motion (`StepperTest`, `StepperManualTest`,
`StepperHoldTest`), the LCD (`DisplayTest`), and the LED ring (`led_wheel_test`).
`platformio.ini.reference` is the build config they were developed under.

Kept for history. None of this is used by the real sketch in `../dsentry-sketch/`.
