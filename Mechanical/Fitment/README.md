# Fitment

Measured values from the fit-test prints in `../Gcode/testing/`.

## Fastener fits

| Fastener | Clearance | Self-tap hole | Counterbore |
|---|---|---|---|
| M2 | 2.7 mm | 2.3 mm | 3.9 mm |
| M3 | 3.6 mm | 3.1 mm | 6.2 mm |
| M4 | 4.5 mm | 4.1 mm | 8.1 mm |

Same values for both vertical and horizontal holes.
